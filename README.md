# Primer Pre-Entrega Git

Este es un repositorio para realizar la pre entrega del modulo de de Git y GutHub de la diplomatura FullStack de CoderHouse

## Tecnologias:

HTML
CSS


### ¿Como empezar?

1. Anda a la carpeta donde quieras clonar el repositorio. 
2. Copia la ruta.
3. Abri CMD y mediante el comando 'cd "ruta_de_la_carpeta" posicionate dentro de ella. 
4. Anda al navegador, copia la URL del repositorio. 
5. En CMD pone el comando 'git clone "URL_QUE_COPIASTE_DEL_NAVEGADOR"'.
6. Listo, tenes el repositorio clonado.
